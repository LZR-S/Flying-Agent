# v0.1 摄影工作台

工作台接入当前 Harness 的公共观察、原生工具事件和照片证据。入口仅支持 Webots 和历史回放。

## 启动

在项目目录执行：

```sh
PYTHONPATH=src .venv/bin/python -m drone_agent dashboard --port 8766 --env-file .env --open
```

本地地址：<http://127.0.0.1:8766>。`--runs` 可指定运行记录根目录。默认凭据文件为 `.env`；首次使用先复制 `.env.example` 为 `.env` 并填写凭据。

- OpenLux 使用所选文件的 `BASE_URL` / `API_KEY`。
- 阿里云官方使用 `AliCloud_url` / `AliCloud_key`，默认模型 `qwen3.8-flash`。
- 自定义接口使用环境变量或所选文件中的 `DRONE_PHOTO_VLM_BASE_URL` / `DRONE_PHOTO_VLM_API_KEY`。
- 工程检查无需凭据：固定脚本起飞、悬停 30 秒、降落、放弃交付，不调用 API。

模型参数继续由现有 `CloudPolicy` 管理；界面不添加推理策略。选择接口会填入对应的默认模型，也可以手动填写模型名。

## 使用

1. 选择场景、接口、模型，填写任务及预算；点击启动才会运行 Webots。
2. 默认取景器显示完整 RGB、虚线输出画幅与框内辅助线；完整 RGB 和成片预览均无标注。决策依据显示该次请求留档的取景器版本；旧记录无标注证据时显示原导航帧。历史滑块回看留档曝光，不生成新帧。辅助线由模型工具选择，界面只展示该设置，不另行叠加浏览器网格。
3. 时间线可以筛选决策、动作、异常，搜索操作说明，展开事件 JSON，并跳转到依据帧。最多保留最近 10,000 个事件，当前筛选显示最近 300 条；完整记录可下载。
4. 点击候选照片可查看像素尺寸、裁剪来源、模型自评与原图；最终交付单独标记。模型自评与独立摄影验收分开显示。
5. 可下载 Trace、结果 JSON、动作/API CSV、独立评测和包含图片的 HTML 报告。

顶部控制条始终显示其控制的任务。切换下方历史记录后，“停止并降落”仍作用于该控制任务。工作台只停止自己启动的任务；命令行另行启动的运行可供回放，但不获得其执行所有权。

## 执行边界

- `Runtime._tick()` 向 `PreviewWriter` 提供已经采集的公共观察；图像编码和写盘在有界队列的后台线程完成，线程不调用传感器或 Webots API。
- 每秒至多发布 8 张预览，只保留最近 24 次发布。高频实时预览不进入 `images.json`、模型上下文或照片目录。模型每轮使用独立留档的取景器，两者共用渲染器；实时预览不代表模型已经看过该帧。推理、长动作和收尾期间均可更新。
- 模型仍只获得原有公共字段；工作台不会改变任务提示、工具权限、依据帧 ID 或动作语义。
- 控制接口只绑定 `127.0.0.1`，写请求检查 Host、Origin 和会话 token；媒体与报告使用路径白名单，不开放凭据、API 原始目录或评测真值目录。
- 同一运行目录的工作台使用进程间租约避免重复启动。停止先写入 `stop.request`；若控制器未初始化或卡住，启动器在默认 50 秒收尾宽限后终止 Webots 模拟器，另有至多 10 秒进程退出等待。没有运行层结果时记为 `operator_stop_no_summary`，不声称已落地。
- 这是 Webots 生命周期管理；不能直接用于控制真机。

## 合成参考图

任务控制区增加“参考图工具”开关，默认允许模型自主生成一次。它使用独立生图凭据，模型接口选择为阿里云时不会将生图请求切到阿里云。缺少生图配置时，模型收到不可用状态，仍可普通摄影；工程脚本模式始终关闭生图。

生成期间显示源图 ID 与等待时间；相机预览和飞控持续运行。新增“合成构图参考”展区，与候选照片分开，标明非实拍、不可交付。照片详情显示模型给出的参考图采用/弃用原因和实拍差异。运行统计单列生图次数与耗时；下载的 HTML/JSON 包含参考来源和记录，生图耗时不并入决策模型 API 耗时。
